# Raw Scheme Documents Directory

This folder stores unedited official government scheme PDFs, HTML exports, and text guidelines.

## Storage Guidelines
* File naming convention: `<scheme_acronym>_<yyyy>.pdf` (e.g., `PM_KISAN_2026.pdf`).
* Every file added here must have a corresponding record in `data/metadata/scheme-sources.csv`.
* Raw files here are converted to structured chunks in `data/processed/schemes/`.
